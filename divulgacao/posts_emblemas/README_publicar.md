## Como exportar para imagem
1. Abre o ficheiro `.html` no Chrome/Edge (duplo clique).
2. Botão direito → **Inspecionar** → `Ctrl+Shift+P` → escreve **screenshot** →
   **Capture node screenshot** (com o `<div class="cv">` selecionado). Sai já no
   tamanho certo (1080×1080 ou 1080×1920).
   - Alternativa simples: `Ctrl+Shift+P` → **Capture full size screenshot**.
3. Se preferires, avisa-me quando o bash voltar e eu exporto os PNG automaticamente.

> Os emblemas são carregados por caminho relativo (`../../crests/`), por isso
> mantém estes ficheiros dentro de `divulgacao/posts_emblemas/`.

## Stories — como maximizar partilhas
- Em cada story de clube, adiciona o **autocolante de menção (@)** ao clube — quando marcas o clube, ele recebe notificação e costuma **repartilhar** para os seguidores dele.
- Adiciona o **autocolante de Link** → gestorfutebol.pt (substituiu o antigo "deslizar para cima"; funciona em qualquer conta).
- Autocolantes extra que ajudam o alcance: **caixa de perguntas** ("qual o próximo clube?") ou **sondagem**.
- Quando um clube repartilhar o teu post no story dele, **repartilha de volta** no teu — dá gás ao alcance e mostra que há adesão.
